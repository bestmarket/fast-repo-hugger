# Import "import-buddy-fast" into this project

The repository is public and is already a Lovable-style app (same framework and setup as this project), so it can be brought over as-is rather than rebuilt.

## What the app is

A video content studio with user accounts:

- Sign-in / sign-up page and a protected app area
- Channels, sources, ideas, scripts, videos, scheduled posts
- AI features (idea/script generation, video analysis, chat)
- A video editor and a production dialog
- A scheduled-posting endpoint that an automated timer can call

## What will be done

1. Copy the full application over this project: all pages, components, shared logic, styles, images, and configuration. The current blank starter page is replaced by the app's own home page.
2. Install the extra packages the app needs (AI toolkit, animation, markdown rendering, database tooling, and others).
3. Turn on Lovable Cloud so the app has its database, accounts, file storage, and server features.
4. Create the database exactly as the app expects: ten tables (profiles, channels, projects, sources, ideas, scripts, videos, posts, source videos, schedule settings), their access rules, the new-user trigger, and the file storage buckets. No existing records come with the repo, so it starts empty.
5. Set up the built-in AI access and the secret used by the scheduled-posting endpoint.
6. Check the result: the app builds, the home page and sign-in page load, and a signed-in run through the main screens works.

## Notes and open points

- The repo contains no user data, so this is a fresh copy of the app, not a data migration.
- Any external services the app expects beyond Lovable's own (for example posting to a social platform) will be reported after the copy if they need keys from you.

## Technical detail

- Source: `github.com/bestmarket/import-buddy-fast` (default branch), TanStack Start v1 + React 19 + Tailwind v4 + Supabase — same stack as this project, so no framework conversion.
- Files copied: `src/**` (routes incl. `_authenticated/*` and `api/public/hooks/scheduled-videos.ts`, components, `lib/*.functions.ts` / `*.server.ts`, integrations), `public/**`, `drizzle/**`, `supabase/config.toml`, config files; `package.json` dependencies merged.
- `src/integrations/supabase/*` and `src/routeTree.gen.ts` are regenerated by the Cloud integration rather than copied verbatim where they conflict.
- Migration applied from `drizzle/migrations/0000_import_speeder_schema.sql` (tables, GRANTs, RLS policies, triggers, storage buckets).
- Secrets: `LOVABLE_API_KEY` (AI gateway) and `LOVABLE_CRON_SECRET` provisioned; Supabase URL/keys come from Cloud.
